# Press / collaboration kit

`playforge-labs-presskit.zip` — 16 files, ~640KB. Hand this to anyone
featuring, hosting, raiding or collaborating with the channel.

The point is that it saves a scramble later **and** stops people butchering
the logo. Everything in it is self-describing: the zip contains its own
`README.txt` covering file choice, clear space and the don'ts, so the
recipient needs nothing from this repository.

## What is in it

- Marks: full and `-tight` cuts, light and dark, plus the small cut for ≤48px
- Lockups: stacked and inline, light and dark
- Wordmarks: stacked, light and dark
- Avatars: `avatar-twitch-800.png`, `avatar-ondark-800.png`
- `mascot.png` — character art with alpha
- `README.txt` — the usage notes

All logo artwork is **outlined SVG**, so Chakra Petch is not required to open
or render any of it. That is deliberate: a press kit that needs a font
install is a press kit that gets ignored.

## Keeping it current

The zip is a snapshot. It carries the `redforge-neutral` lockup family and
the marks — none of which have changed since it was built — so it is current
as of this writing. **Rebuild it if the mark, the wordmark or the mascot
changes**, and check with `unzip -l presskit/*.zip` if you are unsure what a
given copy contains.

It deliberately does **not** include overlays, alerts, emotes or badges.
Those are channel furniture, not identity, and shipping them invites use you
did not intend.
